# notes_v23 — held-out Singapore-style clinical/admin notes with gold spans.
# SYNTHETIC: NOT REAL PATIENT DATA. Every person, name, NRIC/FIN, MRN, phone number, address, email and health detail below is invented for testing; any match to a real person, number or mailbox is coincidental.
# Author: writer H. Written from general knowledge only, by an author who did not see the system under test, its rules, or earlier evaluation sets.
# Theme of this set: hospital operations and support services (billing, claims, counselling, occupational health,
#   security, transport, medical records, IT, biomedical engineering, pharmacy, call centre, feedback, belongings,
#   mortuary). Hospitals, clinics, companies and agencies named below are invented decoys.
# FORMAT: a note starts with a line "=== v23_nNN | <kind> ===" and its text is every following line up to the next
#   "===" header line. A gold span is written inline as {{label|text}}; only "text" belongs to the note text.
#   Spans are never nested, never contain "{{", "}}" or "|", and have no leading/trailing spaces.
#   Anything not inside {{...}} is not an identifier.
# LABELS: identifiers = name, national_id, mrn, case_visit, address, postal_code, phone, fax, email, dob,
#   date_of_death, device, biometric, photo, other_id. SHI = hiv_sti, mental_health, substance_use, genetic,
#   reproductive_sexual, other_sensitive. Other = date_other (dates of a person's care/events that are not DOB or
#   date of death).
# CONVENTIONS:
#   - Honorifics/titles (Dr, Mr, Mrs, Ms, Mdm, SN, SSN, HCA, Sgt, Prof, A/Prof, Daw, aunty, doctor...) are outside
#     name spans. Every person is named: patients, relatives, carers, staff, clinicians, employers, callers.
#     Every mention is labelled, including repeats, surnames alone, given names alone, nicknames and initials.
#   - INITIALS used for a person (in any form) are labelled name.
#   - "Singapore" and the postal code are outside address spans; the postal code is its own postal_code span and
#     keeps an "S" prefix inside the span when written like "S560123".
#   - Organisation names (hospitals, clinics, companies, ministries, agencies, law firms) are decoys, NEVER marked.
#     But every phone, fax, email, street address and postal code is ALWAYS marked wherever it appears, including
#     letterheads, footers, switchboards, hotlines, department faxes and generic mailboxes. Company/organisation
#     registration numbers (UEN, Co. Reg. No., ROC) are marked other_id.
#   - Field captions (NRIC, FIN, MRN, Tel, Fax, HP, DID, UEN, IMEI, S/N) are outside spans; only the value is labelled.
#   - national_id = NRIC/FIN/passport/birth-certificate numbers, including masked and partial forms.
#   - mrn = hospital record numbers; case_visit = admission/visit/encounter/appointment numbers of an episode;
#     device = device serial numbers, IMEI, in-vehicle unit numbers and vehicle plates; other_id = any other
#     identifying number/code/handle/URL tied to a person or organisation (bill, claim, policy, incident, booking,
#     employee/staff, user-ID/login, lab/radiology accession, court/police references, registration numbers).
#   - Decoys left unmarked: organisation names, ward/bed/room/clinic numbers, lab values, doses, times, drug batch
#     and lot numbers, equipment model numbers, form/policy/tender/protocol document numbers, generic dates
#     not about a person (effective dates, policy versions), queue numbers, visitor pass numbers.
#   - Dates tied to a person's care or to an event involving an identifiable person are date_other.
#   - Emails/URLs use only example.com / example.org / example.net (and their subdomains).
# NEGATIVE CONTROLS (no spans at all): v23_n05, v23_n11, v23_n16, v23_n22, v23_n28.
# DELIBERATELY INVALID IDs: in v23_n32 the NRIC "S6089694F" (a transposition of S6089649F as typed on a
#   purchase order) has an INVALID checksum on purpose; it is still labelled national_id. Also in v23_n32 the
#   DOB "1998-07-41" is an impossible date (HR typo) and is still labelled dob. All other full NRIC/FIN values
#   have valid checksums.

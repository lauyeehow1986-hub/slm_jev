# notes_v11 — held-out Singapore-style clinical/admin notes with gold spans.
# SYNTHETIC: NOT REAL PATIENT DATA. Every person, name, NRIC/FIN, MRN, phone number, address, email and health detail below is invented for testing; any match to a real person, number or mailbox is coincidental.
# Written by an author who did not see the system under test, its rules, or earlier evaluation sets.
# Hospital/clinic/company names (e.g. Kallang River General Hospital, KRGH) are invented decoys.
#
# FORMAT
# - Header lines start with "# ". A note starts with "=== v11_nNN | <kind> ===" and runs to the next "===" header line.
# - A gold span is written inline as {{label|text}}; the note text contains only "text". Spans are never nested,
#   never contain "{{", "}}" or "|", and have no leading/trailing spaces. A few spans deliberately contain a line break
#   (identifiers split across lines, e.g. an OCR-wrapped address). Anything outside {{...}} is not an identifier.
#
# LABELS
# - identifiers: name, national_id, mrn, case_visit, address, postal_code, phone, fax, email, dob, date_of_death,
#   device, biometric, photo, other_id
# - SHI: hiv_sti, mental_health, substance_use, genetic, reproductive_sexual, other_sensitive
# - other: date_other (any date of the patient's care/events that is not a DOB or a date of death)
#
# CONVENTIONS
# - Honorifics/titles (Dr, Mr, Mrs, Ms, Mdm, Madam, Pn, SN, SSN, NC, Sgt, Cpl, Pte, Insp, SSgt, Prof, A/Prof, Uncle, Auntie)
#   are outside name spans. Every person is named, including relatives, staff, callers and witnesses. HL7 names
#   split by "^" are labelled per component.
# - "Singapore"/"S'pore" is outside address spans; the postal code is its own postal_code span (an "S" prefix, when
#   written, stays inside the span). Foreign city/country names are outside address spans.
# - Date of death of any person (including relatives) is date_of_death; dates of letters, messages, admissions,
#   appointments, tests and procedures about the patient are date_other; guideline/version/deadline dates are not marked.
# - Practitioner registration numbers (MCR, SNB, DCR, PRN, TCM), police/claim/court/lab/transfusion/study/bill refs,
#   work permit numbers, bank accounts and courier tracking numbers are other_id. Vehicle plates and IMEIs are device.
# - Institutional names, ward/bed numbers, model/lot numbers, protocol document numbers, ICD codes and extensions
#   written alone are decoys and are not marked.
#
# DELIBERATELY INVALID / CORRUPTED / MASKED national_id SPANS (all still labelled national_id)
# - v11_n03 "Sl558O3OE": OCR-corrupted (l for 1, O for 0); underlying valid NRIC S1558030E.
# - v11_n24 "T0891471H": deliberately INVALID checksum (valid check letter would be G); mis-transcribed on the form.
# - v11_n32 "S 1394 514 D": unusual spacing; valid (S1394514D) once spaces are removed.
# - v11_n09 "S****892Z" and v11_n21 "S****490B": partially masked, not checksum-verifiable.
# - Passport numbers (v11_n04 "C7731904", v11_n09 "EJ4418273", v11_n30 "BW0418827") have no checksum.
# Other OCR noise (l for 1/I, O for 0) appears inside the v11_n03 name, DOB, phone, address and postal code spans.

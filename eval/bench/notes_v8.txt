# notes_v8 — held-out Singapore-style clinical/admin notes with gold spans.
# SYNTHETIC: NOT REAL PATIENT DATA. Every person, name, NRIC/FIN, MRN, phone number, address, email and health detail below is invented for testing; any match to a real person, number or mailbox is coincidental.
# Author: written from general knowledge by an author who did not see the system under test, its rules, its code, or any earlier evaluation sets.
# FORMAT: each note starts with a header line "=== v8_nNN | <kind> ===". The note text is every line after it up to the next "===" header line.
# FORMAT: a gold span is written inline as {{label|text}}; the note text contains only "text". Spans are never nested. Anything outside {{...}} is not an identifier.
# LABELS (identifiers): name, national_id, mrn, case_visit, address, postal_code, phone, fax, email, dob, date_of_death, device, biometric, photo, other_id
# LABELS (SHI): hiv_sti, mental_health, substance_use, genetic, reproductive_sexual, other_sensitive
# LABELS (other): date_other = any date of a person's care/events (incl. letter/message dates about a patient) that is not a DOB or date of death.
# CONVENTIONS: honorifics/titles (Dr, Mr, Mrs, Ms, Mdm, SN, SSN, Sgt, Insp, A/Prof, etc.) are outside name spans. Every person is named-span'd, incl. staff, relatives, employers, callers, chat senders, sign-offs.
# CONVENTIONS: "Singapore" and the postal code are outside address spans; the postal code is its own postal_code span (keeps an "S" prefix inside when written "S419124").
# CONVENTIONS: national_id = NRIC/FIN/passport/birth certificate numbers (incl. partially masked ones); mrn = hospital record numbers; case_visit = visit/admission/encounter/appointment/case numbers of a hospital episode;
# CONVENTIONS: device = device serials, vehicle plates, IMEI; photo = references to photographs of a person (photo file names); other_id = any other identifying number/code/handle (policy, claim, lab accession, practitioner registration, employee, work permit, feedback, police/court refs, blood unit numbers).
# CONVENTIONS: tobacco smoking is not labelled as SHI; dementia/memory loss is not labelled as SHI. Emails/URLs use only example.com/.org/.net domains.
# DECOYS left unmarked: hospital/clinic/company/ministry/school names, ward/bed/room numbers, lab values, doses, times, codes, device model numbers, protocol/document numbers and dates, lot numbers.
# NEGATIVE CONTROLS (no identifiers at all): v8_n06, v8_n14, v8_n20, v8_n27, v8_n32.
# DELIBERATELY INVALID ID: in v8_n22 the NRIC "S8012345A" (a transcription error on a referral form) has an invalid checksum on purpose (correct letter would be J); it is still labelled national_id. All other full NRIC/FIN values have valid checksums. "S****382J" in v8_n17 is partially masked.

# notes_v22 — held-out Singapore-style clinical/admin notes with gold spans.
# SYNTHETIC: NOT REAL PATIENT DATA. Every person, name, NRIC/FIN, MRN, phone number, address, email and health detail below is invented for testing; any match to a real person, number or mailbox is coincidental.
# Author: writer G (specialist and sensitive services). Written from general knowledge only, by an author who did not see
#   the system under test, its rules, its code, or any earlier evaluation sets.
# FORMAT: a note starts with a header line "=== v22_nNN | <kind> ===". The note text is every line after it up to the next
#   "===" header line. No comment lines appear inside notes.
# SPANS: gold spans are inline as {{label|text}}. The note text contains only "text"; braces and "label|" are markup.
#   Spans are never nested; span text has no "{{", "}}", "|" and no leading/trailing spaces. Anything outside {{...}}
#   is not an identifier.
# LABELS (identifiers): name, national_id, mrn, case_visit, address, postal_code, phone, fax, email, dob, date_of_death,
#   device, biometric, photo, other_id
# LABELS (SHI): hiv_sti, mental_health, substance_use, genetic, reproductive_sexual, other_sensitive
# LABELS (other): date_other = any date of the patient's care/events that is not a DOB or date of death.
# CONVENTIONS:
#   - Honorifics/titles (Dr, Mr, Mrs, Ms, Mdm, SN, SSN, Insp, Prof, A/Prof ...) are outside name spans. Every mention of a
#     person is labelled name: patients, relatives, carers, staff, clinicians, officers, callers; repeated mentions,
#     surnames alone after a title, given names alone, nicknames, names in Chinese characters, lower-case names.
#   - INITIALS used for a person (any form: "N.K.", "YL", "K. Raj", "DK") are labelled name.
#   - "Singapore" and the postal code are outside address spans; the postal code is its own postal_code span and keeps an
#     "S" prefix inside the span when written like "S730638".
#   - Letterheads and institutional contacts: institution, hospital, clinic, company and ministry NAMES are decoys and are
#     NOT marked; but EVERY phone number, fax number, email address, street address and postal code is marked wherever it
#     appears (letterheads, footers, switchboards, hotlines, department faxes, generic mailboxes). Organisation
#     registration numbers (UEN, company reg. no.) are other_id.
#   - Field captions (NRIC, FIN, BC, MRN, Tel, Fax, HP, DID, UEN, ext) are outside spans; only the value is labelled.
#     A phone extension written with the number is inside the phone span.
#   - national_id: NRIC/FIN/birth certificate/passport numbers, including masked ones. mrn: hospital record numbers;
#     case_visit: admission/visit/episode/cycle numbers of a hospital episode; device: serial numbers/asset tags of
#     devices worn or used by the patient; other_id: any other identifying number/code/handle (lab accession numbers,
#     policy/claim refs, police/court/coroner refs, practitioner registration numbers, social-media handles, study IDs,
#     work permit numbers, baby tags, embryo straw labels). photo: file names/IDs of identifiable patient photographs.
#     biometric: fingerprint/thumbprint record identifiers.
#   - Decoys left unmarked: institution names, ward/bed/room/incubator numbers, lab values, doses, times, ICD codes,
#     device model names, form/protocol/document numbers, guideline version dates, emergency service names.
#   - SHI terms in the generic negative-control notes (teaching case, formulary) are not about any person and are unmarked.
# NEGATIVE CONTROLS (no spans at all): v22_n10, v22_n15, v22_n21, v22_n24, v22_n29.
# DELIBERATELY INVALID ID: in v22_n26 the NRIC "S7388946E" has a wrong check letter (valid would be S7388946D); it is
#   still labelled national_id. All other NRIC/FIN values have valid checksums. Masked IDs (e.g. "S****465D") and
#   foreign passports are not checksum-tested.

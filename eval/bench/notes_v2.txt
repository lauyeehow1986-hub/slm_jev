# notes_v2 — held-out Singapore-style clinical/admin notes with gold spans.
#
# SYNTHETIC: NOT REAL PATIENT DATA. Every person, name, NRIC/FIN, MRN, phone number, address,
# email and health detail below is invented for testing; any match to a real person, number or
# mailbox is coincidental. Written by an author who did not see the system under test, its rules,
# or earlier evaluation sets (a separate Claude session briefed only with the format and the
# label list). Before any system was run on it, email domains and the one social-media URL
# were moved to reserved example.* domains so no real mailbox or profile can be implied; the
# gold spans and labels are the author's, unchanged.
#
# Format: a note starts with "=== <id> | <kind> ===". The note text is every line after that
# header up to the next "===" header line. Lines starting with "#" are comments and are dropped
# (they are not part of any note). A gold span is written inline as {{label|text}}: the note text
# contains only "text" (the braces and "label|" are markup and must be stripped), and "text" is
# exactly the characters that appear in the note. Spans are never nested and span text never
# contains "{{", "}}" or "|". Anything not inside {{...}} is not an identifier (bed/ward numbers,
# lab values, times, dosages, ICD codes, device model numbers, hospital and company names are
# deliberate decoys and are left unmarked).
#
# Labels:
#   identifiers: name, national_id, mrn, case_visit, address, postal_code, phone, fax, email,
#                dob, date_of_death, device, biometric, photo, other_id
#   SHI:         hiv_sti, mental_health, substance_use, genetic, reproductive_sexual,
#                other_sensitive
#   other:       date_other (any date that is not a DOB or date of death)
# Conventions: honorifics/titles (Dr, Mr, Mdm, Ms, SN, Sgt, Pn, Daw, A/Prof) are outside name
# spans; "Singapore" and the postal code are outside address spans; a postal code keeps its "S"
# prefix inside the span when written that way. Intentionally INVALID-checksum NRICs are
# commented on in the note they occur in (see v2_n16).

=== v2_n32 | clinical protocol ===
CLINICAL PROTOCOL - ACUTE HYPERKALAEMIA IN ADULTS (ICD-10 E87.5)
Mild K 5.5-5.9 mmol/L; moderate 6.0-6.4; severe >= 6.5 or any ECG changes.
1. Repeat K (non-haemolysed sample) and do a 12-lead ECG immediately.
2. If ECG changes: calcium gluconate 10% 30mL IV over 10 min; may repeat up to 3 doses.
3. Insulin-dextrose: 10 units Actrapid + 50mL D50W (or 125mL D20W) IV over 15 min; check CBG hourly for 6h.
4. Salbutamol 10-20mg nebulised as adjunct.
5. Sodium polystyrene sulfonate 15g PO tds, or sodium zirconium cyclosilicate 10g tds for 48h.
6. Recheck K at 1, 2, 4 and 6 hours. Refer renal on call for K >= 6.5 refractory to treatment or for anuric patients (consider urgent dialysis).
7. Stop ACE-I/ARB, spironolactone, NSAIDs and potassium supplements.
Order set code ORD-HK-001. Document in the resuscitation chart; escalate to the registrar if the patient is in Bed 1-6 of the HD unit.

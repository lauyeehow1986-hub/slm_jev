# notes_v26 — held-out Singapore-style clinical/admin notes with gold spans.
# SYNTHETIC: NOT REAL PATIENT DATA. Every person, name, NRIC/FIN, MRN, phone number, address, email and health detail below is invented for testing; any match to a real person, number or mailbox is coincidental.
# Author: writer K (theme: digital health and data exchange). Written from general knowledge only, by an author who did not see the system under test, its rules, or earlier evaluation sets.
# FORMAT: a note starts with a header line "=== v26_nNN | <kind> ==="; the note text is every line after it up to the next "===" header line.
# Gold spans are inline as {{label|text}}; the note text contains only "text". Spans are never nested, contain no "{{", "}}" or "|", and have no leading/trailing spaces. Anything outside {{...}} is not an identifier.
# LABELS (identifiers): name, national_id, mrn, case_visit, address, postal_code, phone, fax, email, dob, date_of_death, device, biometric, photo, other_id
# LABELS (SHI): hiv_sti, mental_health, substance_use, genetic, reproductive_sexual, other_sensitive
# LABEL (other): date_other = a date of a patient's care, events or communications about that patient that is not a DOB or date of death (only the date part; clock times stay outside).
# CONVENTIONS:
# - Honorifics/titles (Dr, DR, Mr, Mrs, Ms, Mdm, SN, RN, Sgt, Prof, A/Prof) are outside name spans. Every mention of a person is labelled name: patients, relatives, carers, staff, clinicians, employers, callers; repeats, lone surnames or given names, nicknames, CAPS, inverted "SURNAME, Given", lower case, Chinese characters, masked names. Role words used as speaker labels (DOCTOR, PATIENT, CAREGIVER, BOT, USER) are not names.
# - INITIALS used for a person (any form, e.g. "MG", "W.S.L.", "K.P.") are labelled name.
# - "Singapore"/"S'pore"/"SINGAPORE" is outside address spans; the postal code is its own postal_code span (an "S" prefix stays inside, e.g. S436891).
# - LETTERHEADS AND INSTITUTIONAL CONTACTS: institution, hospital, clinic, company and ministry NAMES are decoys and never marked. Every phone, fax, email, street address and postal code is marked wherever it appears (letterheads, footers, switchboards, hotlines, emergency numbers, department faxes, generic mailboxes). Organisation registration numbers (UEN, HCI licence code) are other_id.
# - Field captions (NRIC, FIN, MRN, Tel, Fax, HP, DID, UEN, WP, MCR ...) are outside spans; only the value is labelled.
# - national_id = NRIC/FIN/passport/foreign national ID (including masked or partial forms); mrn = hospital record number; case_visit = visit/admission/encounter/session numbers of a care episode; device = serials/IMEI/vehicle plates of devices tied to the person; photo = face/full-body images or ID-card captures and their file references; biometric = biometric template references; other_id = other identifying numbers, codes, handles, URLs, IP addresses, employee/practitioner numbers, accession numbers, resource ids, referral/order/case refs tied to a person.
# - Decoys left unmarked: organisation names, ward/bed/room numbers, lab values, doses, times, ICD/LOINC codes, device model numbers, firmware versions, protocol/IRB/document/incident/change-request numbers, interface message-control and batch IDs, vaccine lot numbers, chatbot names, wound photos, and dates not about a specific patient (release/version dates, cohort ranges, incident-log times, form-signing dates in non-patient documents).
# - Emails/URLs use only example.com / example.org / example.net subdomains; IP addresses use documentation ranges.
# - Negative controls (no spans at all): v26_n06, v26_n13, v26_n19, v26_n22, v26_n28.
# DELIBERATELY INVALID / NON-STANDARD IDs (still labelled national_id): v26_n08 "S94B234OD" is an OCR-corrupted NRIC (letters B/O in place of digits; not checksum-valid as written). Masked/partial forms "S****366D", "S****711D", "F****628W", "TXXXX096C", "G547****Q" and "423A" are intentional; the spoken NRIC in v26_n09 is valid once spaces are removed; v26_n26 "880412-14-5527" is a Malaysian MyKad number (no NRIC checksum); "P4417902B" and "K4471902P" are passport numbers.

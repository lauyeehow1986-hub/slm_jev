# notes_v17 — held-out Singapore-style clinical/admin notes with gold spans.
# SYNTHETIC: NOT REAL PATIENT DATA. Every person, name, NRIC/FIN, MRN, phone number, address, email and health detail below is invented for testing; any match to a real person, number or mailbox is coincidental.
# Writer B set: administrative, legal and community correspondence. Written from general knowledge by an author who did not see the system under test, its rules, or any earlier evaluation sets.
# FORMAT: each note starts with a header line "=== v17_nNN | <kind> ===". The note text is every line after it up to the next "===" header line.
# A gold span is written inline as {{label|text}}. Only "text" belongs to the note; the braces and "label|" are markup. Spans are never nested.
# Anything not inside {{...}} is not an identifier.
# LABELS (identifiers): name, national_id, mrn, case_visit, address, postal_code, phone, fax, email, dob, date_of_death, device, biometric, photo, other_id
# LABELS (SHI): hiv_sti, mental_health, substance_use, genetic, reproductive_sexual, other_sensitive
# LABELS (other): date_other = any date of a specific person's care or events that is not a DOB or date of death.
# CONVENTIONS:
# - Honorifics and titles (Dr, Mr, Mrs, Ms, Mdm, SN, EN, SSgt, Cpl, Insp, SI, A/Prof, Encik, Nurse, Auntie, Uncle) are outside name spans. Kinship words (Ah Ma) are not names.
# - Every mention of a person is labelled name, including repeats, surnames alone, given names alone, nicknames, lower-case names, Chinese-character names and INITIALS.
# - "Singapore" is outside address spans; the postal code is its own postal_code span and keeps an "S" prefix when written like S730688.
# - Institution, hospital, clinic, company, school, embassy and ministry NAMES are decoys and never marked. But every phone, fax, email, street address and postal code is marked wherever it appears, including letterheads, footers, switchboards, hotlines, department faxes and generic mailboxes.
# - Organisation registration numbers (UEN, Co. Reg., GST Reg., charity reg., agency licence) are other_id.
# - Field captions (NRIC, FIN, MRN, Tel, Fax, HP, DID, UEN) are outside spans; only the value is labelled.
# - national_id: NRIC/FIN/passport/birth certificate numbers (masked forms included). mrn: hospital record numbers. case_visit: visit/admission/encounter numbers of a hospital episode. device: serial numbers and vehicle plates. photo: identifiable photograph file references. other_id: any other identifying number/code (policy, claim, bill, police report, court, coroner, PPO, work permit, staff/employee, study/screening numbers, practitioner MCR numbers, bank accounts, accession numbers, death certificate, air waybill).
# - Dates tied to a specific person's case (including dates of letters, emails and chat messages about that person) are date_other. Generic dates (effective dates, protocol version dates) are unmarked.
# - Decoys left unmarked: ward/bed/room numbers, lab values, doses, times, protocol/form/circular numbers, flight numbers, model numbers.
# - Negative controls (no spans at all): v17_n04, v17_n10, v17_n16, v17_n21, v17_n27.
# DELIBERATELY INVALID ID: in v17_n13 the husband mistypes his wife's NRIC as S7702165F (checksum invalid); it is still labelled national_id.

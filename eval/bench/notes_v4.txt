# notes_v4 — held-out Singapore-style clinical/admin notes with gold spans.
# SYNTHETIC: NOT REAL PATIENT DATA. Every person, name, NRIC/FIN, MRN, phone number, address, email and health detail below is invented for testing; any match to a real person, number or mailbox is coincidental.
# Hospital, clinic, company, school, law-firm and ministry names are invented or public decoys and are NOT identifiers.
# Author: written from general knowledge by an author who did not see the system under test, its rules, its code, or any earlier evaluation sets.
#
# FORMAT
# - A note starts with a header line "=== v4_nNN | <kind> ===". The note text is every line after it up to the next "===" header line.
# - A gold span is written inline as {{label|text}}. The note text contains only "text"; the braces and "label|" are markup.
# - Spans are never nested; span text never contains "{{", "}}" or "|", and has no leading/trailing spaces.
# - Anything not inside {{...}} is not an identifier.
#
# LABELS
# - identifiers: name, national_id, mrn, case_visit, address, postal_code, phone, fax, email, dob, date_of_death, device, biometric, photo, other_id
# - SHI: hiv_sti, mental_health, substance_use, genetic, reproductive_sexual, other_sensitive
# - other: date_other (any date of the patient's care/events that is not a DOB or date of death)
#
# CONVENTIONS
# - Honorifics/titles/kinship titles (Dr, Mr, Mrs, Ms, Mdm, MDM, SN, SSN, Sgt, Insp, Prof, A/Prof, Auntie) are OUTSIDE name spans.
#   Every person is named with a name span: patients, relatives, carers, staff, clinicians, employers, witnesses, callers.
#   Chinese-character names are separate name spans from the romanised form. Initials used as a person's sign-off are name spans.
# - "Singapore" and the postal code are OUTSIDE address spans; the postal code is its own postal_code span and keeps an "S" prefix inside the span when written like "S560123".
# - national_id: NRIC/FIN/passport/birth-certificate numbers, including partially masked ones.
# - mrn: hospital record numbers; case_visit: visit/admission/encounter/episode numbers; device: device serials, vehicle plates, IMEI;
#   other_id: any other identifying number/code/handle/URL (policy, claim, accession, donation, study, court, practitioner registration, card numbers, social handles).
# - All written-out phone and fax numbers are labelled, including institutional ones; bare internal extensions (e.g. "ext 5518") are decoys.
# - All email addresses are labelled (reserved example.* domains only).
# - Dates of patient-specific letters/messages/calls count as date_other; version/effective dates of generic documents are decoys.
# - SHI spans cover the sensitive finding/diagnosis phrase only, not surrounding dose or narrative text.
# - Decoys left unmarked: institution names, ward/bed/room/clinic numbers, lab values, doses, times, ICD/SNOMED codes, model numbers, protocol numbers.
#
# DELIBERATELY INVALID / NON-CHECKSUMMABLE IDS
# - v4_n10: "S8727221B" is a deliberately INVALID NRIC checksum (typo in a referral; the correct form S8727221D also appears). Still labelled national_id.
# - v4_n14: "SXXXX899H" is a partially masked NRIC (not checksummable). Labelled national_id.
# - Passport numbers (EH0931776, MF482219, P4829163B) are not NRIC/FIN-shaped and have no checksum.
#
# NEGATIVE CONTROLS (no identifier spans at all): v4_n05, v4_n11, v4_n19, v4_n27, v4_n32.

Case A: A 72-year-old woman on a thiazide presents with confusion. Serum Na 118 mmol/L, serum osmolality 250 mOsm/kg, urine Na 45 mmol/L. Discuss thiazide-induced hyponatraemia and the risk of overcorrection.
Case B: A 45-year-old man with small-cell lung cancer has euvolaemic hyponatraemia. Urine osmolality 480 mOsm/kg. Discuss SIADH and the role of fluid restriction, salt tablets and tolvaptan.
Key teaching points:
1. Correct chronic hyponatraemia by no more than 8–10 mmol/L in 24 hours (6–8 mmol/L if high risk of osmotic demyelination).
2. Use 3% saline 100–150 mL boluses for severe symptoms (seizures, GCS drop).
3. Always check glucose, lipids and protein before labelling it true hypotonic hyponatraemia.
Reading: European clinical practice guideline on hyponatraemia, 2014; local ward protocol MED-P-022 v4.

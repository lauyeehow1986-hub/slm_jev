# notes_v14 — held-out Singapore-style clinical/admin notes with gold spans.
# SYNTHETIC: NOT REAL PATIENT DATA. Every person, name, NRIC/FIN, MRN, phone number, address, email and health detail below is invented for testing; any match to a real person, number or mailbox is coincidental.
# Author: written from general knowledge by an author who did NOT see the system under test, its rules, its code, or any earlier evaluation sets.
#
# FORMAT
# - A note starts with a header line "=== v14_nNN | <kind> ===". The note text is every line after it up to the next "===" header line.
# - Gold spans are inline as {{label|text}}. The note text contains only "text"; the braces and "label|" are markup.
# - Spans are never nested; span text never contains "{{", "}}" or "|" and has no leading/trailing spaces.
# - A span MAY contain a line break where a name, address or ID is split across lines (OCR, wrapping); the newline is part of the span text.
# - Anything not inside {{...}} is not an identifier.
#
# LABELS
# - identifiers: name, national_id, mrn, case_visit, address, postal_code, phone, fax, email, dob, date_of_death, device, biometric, photo, other_id
# - SHI: hiv_sti, mental_health, substance_use, genetic, reproductive_sexual, other_sensitive
# - other: date_other (any date of the patient's care/events that is not a DOB or date of death; e-mail/chat/fax timestamps about a patient count)
#
# CONVENTIONS
# - Honorifics/titles (Dr, Mr, Mrs, Ms, Mdm, Encik, SN, SSN, Sgt, Insp, Prof, A/Prof, Fr, Nurse, Ma'am) are OUTSIDE name spans.
# - Every person is named as a span: patients, relatives, carers, staff, clinicians, employers, callers. Surnames alone and given names alone are labelled name.
# - INITIALS used for a person (e.g. "KPL", "JK", "SJP", "S. Lakshmi") are labelled name. A name spelled out letter by letter ("T-O-H") is labelled name.
# - Names in Chinese or Tamil script are labelled name, separately from the romanised form.
# - "Singapore"/"Singapura"/"新加坡" and the postal code are OUTSIDE address spans; the postal code is its own postal_code span (an "S" prefix stays inside it).
# - national_id: NRIC/FIN/passport/birth certificate numbers, including partially masked ones ("S****432J") and spoken-out ones.
# - mrn: hospital record numbers; case_visit: visit/admission/encounter/account/appointment numbers of an episode; device: serial numbers, vehicle plates;
#   other_id: other identifying codes (practitioner MCR/TCM registration, employee/user IDs and log-in names, lab accession and blood-unit numbers,
#   policy/claim/invoice/bank account numbers, work permit numbers, coroner case numbers, client numbers, social-media handles, certificate serials).
# - Decoys left UNMARKED: institution/company/ministry names, institutional letterhead and footer addresses and switchboard/hotline numbers,
#   company UENs, ward/bed/room numbers, lab values, doses, times, ICD codes, device model numbers, document/protocol numbers, generic dates.
# - Emails/URLs use only example.com / example.org / example.net or their subdomains.
#
# DELIBERATELY INVALID IDs
# - S8831722Q in note v14_n26 is a deliberately invalid NRIC checksum (an old mis-keyed registration); it is still labelled national_id.
#

    SpO2 below 92% on room air, suspected sepsis with lactate 4 or more.
P3: limb injuries with intact distal pulses, abdominal pain with stable vitals, fever without red flags.
P4: minor complaints; redirect to GP or polyclinic where appropriate.

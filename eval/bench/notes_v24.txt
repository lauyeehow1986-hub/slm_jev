# Author: writer I (public health, pre-hospital, forensic and institutional health). Written from general knowledge only, by an
#   author who did not see the system under test, its rules, its code, or any earlier evaluation set.
# FORMAT: a note starts with a line "=== v24_nNN | <kind> ===". The note text is every line after it up to the next "===" line.
#   A gold span is written inline as {{label|text}}; the note text contains only "text". Spans are never nested and never
#   contain "{{", "}}" or "|", and have no leading/trailing spaces. Anything outside {{...}} is not an identifier.
# LABELS (identifiers): name, national_id, mrn, case_visit, address, postal_code, phone, fax, email, dob, date_of_death,
#   device, biometric, photo, other_id.
# LABELS (SHI): hiv_sti, mental_health, substance_use, genetic, reproductive_sexual, other_sensitive.
# LABELS (other): date_other = any date of the patient's/person's care or case events that is not a DOB or date of death.
# CONVENTIONS:
#   - Honorifics/titles/ranks (Dr, Mr, Mrs, Ms, Mdm, SN, Sgt, Insp, CPT (Dr), Capt, Sr, Daw, HCA, etc.) are OUTSIDE name spans.
#     Every person is named and every mention is labelled: repeated mentions, lone surnames/given names, nicknames, lower case,
#     CAPS, inverted "SURNAME, Given", Chinese characters (own span), and INITIALS used for a person (labelled name).
#   - "Singapore" is outside address spans; the postal code is its own postal_code span, keeping an "S" prefix if written "S560123".
#   - Letterheads and institutional contacts: organisation/hospital/clinic/company/ministry NAMES are decoys (unmarked), but EVERY
#     phone, fax, email, street address and postal code is marked wherever it appears (letterheads, footers, switchboards,
#     hotlines, department faxes, generic mailboxes). Company/organisation registration numbers (UEN, ROC, licence no.) = other_id.
#   - Field captions (NRIC, FIN, MRN, Tel, Fax, HP, DID, UEN) are outside spans; only the value is labelled.
#   - national_id = NRIC/FIN/passport/birth certificate numbers. mrn = hospital/clinic medical record numbers.
#     case_visit = visit/admission/encounter/episode numbers, including ambulance (SCDF) incident numbers and MCI triage tag numbers.
#     other_id = police/coroner/court/notification/board references, inmate/detainee/supervision numbers, practitioner
#     registration (MCR) numbers, service numbers, work-permit numbers, lab accession numbers, donor/donation numbers,
#     seaman's book numbers, social-media handles and profile URLs, registration numbers.
#     device = vehicle plates and vessel identifiers (IMO number, call sign), implant serial numbers.
#     biometric = fingerprint record references.
#   - Abuse/violence/sexual-assault allegations = other_sensitive. Pregnancy/pregnancy tests = reproductive_sexual.
#     Alcohol/tobacco/drug use and drug test results = substance_use. Positive and negative HIV/STI results = hiv_sti.
#   - Decoys left unmarked: institution names, ward/bed/room/cell numbers, lab values, doses, times, ICD codes, form/circular/
#     guideline numbers and their dates, model numbers, flight numbers, vessel names, ambulance call signs, certificate numbers
#     of ships/premises, aggregate statistics.

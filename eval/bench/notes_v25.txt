# notes_v25 — held-out Singapore-style clinical/admin notes with gold spans.
# SYNTHETIC: NOT REAL PATIENT DATA. Every person, name, NRIC/FIN, MRN, phone number, address, email and health detail below is invented for testing; any match to a real person, number or mailbox is coincidental.
# Written by an author (writer J) who did not see the system under test, its rules, or any earlier evaluation sets. Theme: surgery, anaesthesia, dental, TCM and private clinics.
# FORMAT: each note begins with a line "=== v25_nNN | <kind> ===". The note text is every line after it up to the next "===" header line.
# Gold spans are inline as {{label|text}}; the note text contains only "text". Spans are never nested, never contain "{{", "}}" or "|", and have no leading/trailing spaces. Anything outside {{...}} is not an identifier.
# LABELS (identifiers): name, national_id, mrn, case_visit, address, postal_code, phone, fax, email, dob, date_of_death, device, biometric, photo, other_id
# LABELS (SHI): hiv_sti, mental_health, substance_use, genetic, reproductive_sexual, other_sensitive
# LABELS (other): date_other = any date of the patient's care/events that is not a DOB or date of death.
# CONVENTIONS:
# - Honorifics/titles (Dr, Mr, Mrs, Ms, Mdm, SN, Prof, A/Prof, etc.) are outside name spans. Every person is named and every mention is labelled, including repeats, surnames alone after a title, given names alone, nicknames, lower-case and Chinese-character names.
# - INITIALS used for a person (in any form) are labelled name.
# - "Singapore" and the postal code are outside address spans; the postal code is its own postal_code span (keeps an "S" prefix inside the span when written e.g. "S228199").
# - Organisation names (hospitals, clinics, companies, ministries, insurers, schools) are decoys and never marked. Every phone, fax, email, street address and postal code is marked wherever it appears, including letterheads, footers, hotlines, switchboards and generic mailboxes. Company/organisation registration numbers (UEN, GST reg. no.) are other_id.
# - Field captions (NRIC, FIN, MRN, Tel, Fax, HP, DID, UEN) are outside spans; only the value is labelled.
# - national_id = NRIC/FIN/passport numbers; full NRIC/FIN values all have VALID checksums. Masked NRICs (e.g. SXXXX960C) are still national_id. No deliberately invalid IDs in this set.
# - mrn = hospital/clinic patient record numbers; case_visit = admission/episode/case numbers; device = serial numbers of devices/implants, vehicle plates; photo = identifiers of clinical photographs of a person; biometric = biometric record references; other_id = any other identifying number, code, handle or URL (practitioner registration nos., policy/claim/invoice/MC nos., lab accession nos., work permit nos., staff IDs, blood unit numbers, bank accounts, social handles).
# - Decoys left unmarked: ward/bed/theatre numbers, drug doses, lab values, times, FDI tooth numbers, acupuncture point codes, TOSP/ICD codes, device model/REF/LOT/batch numbers, autoclave cycle numbers, eponyms (e.g. Calot's triangle), document version dates.
# - Emails/URLs use only example.com / example.org / example.net (or subdomains).
# - 5 negative-control notes contain no spans at all: v25_n22, v25_n23, v25_n24, v25_n25, v25_n26.

# notes_v18 — held-out Singapore-style clinical/admin notes with gold spans.
# SYNTHETIC: NOT REAL PATIENT DATA. Every person, name, NRIC/FIN, MRN, phone number, address, email and health detail below is invented for testing; any match to a real person, number or mailbox is coincidental.
# Author: writer C. Written by an author who did not see the system under test, its rules, or any earlier evaluation sets.
# Focus of this set: messages, forms, tables and machine output.
# FORMAT: each note starts with a line "=== v18_nNN | <kind> ===". The note text is every line after it up to the next "===" header line.
# Gold spans are inline as {{label|text}}; only "text" is part of the note. Spans are never nested, never contain "{{", "}}" or "|", and have no leading/trailing spaces. Anything outside {{...}} is not an identifier.
# LABELS (identifiers): name, national_id, mrn, case_visit, address, postal_code, phone, fax, email, dob, date_of_death, device, biometric, photo, other_id
# LABELS (SHI): hiv_sti, mental_health, substance_use, genetic, reproductive_sexual, other_sensitive
# LABELS (other): date_other = any date of the patient's care/events that is not a DOB or date of death.
# CONVENTIONS:
# - Honorifics/titles (Dr, Mr, Mrs, Ms, Mdm, SN, Sgt, Cpl, Insp, Prof, A/Prof, Encik, Cik, Pn., Bu, Daw, திரு., 医师 ...) are OUTSIDE name spans.
# - Every mention of a person is labelled: patients, relatives, carers, staff, clinicians, employers, callers; including repeats, surnames alone,
#   given names alone, nicknames, lower-case names, user names that spell a person's name, and INITIALS (initials used for a person are labelled name).
# - A name broken across a line by OCR is labelled as two name spans, one per line. HL7 "SURNAME^GIVEN" is one name span.
# - "Singapore"/"Singapura" and the postal code are OUTSIDE address spans; the postal code is its own postal_code span and keeps an "S" prefix
#   inside the span when written like "S534208".
# - LETTERHEADS AND INSTITUTIONAL CONTACTS: organisation names (hospitals, clinics, companies, agencies, ministries, schools) are decoys and NOT
#   marked. EVERY phone number, fax number, email address, street address and postal code is marked wherever it appears, including letterheads,
#   footers, switchboards, hotlines, department faxes and generic mailboxes. Organisation registration numbers (UEN, ROC, licence no.) are other_id.
# - Field captions (NRIC, FIN, MRN, Tel, Fax, HP, DID, UEN, ...) are outside spans; only the value is labelled.
# - national_id: NRIC/FIN/passport/birth certificate numbers, including partially masked ones and "last 4" fragments.
#   mrn: hospital/polyclinic record numbers (also masked). case_visit: visit/admission/encounter/appointment/home-care visit/ambulance case numbers.
#   device: serial numbers, vehicle plates, IMEI. biometric: biometric template/enrolment IDs. photo: identifying photo file references.
#   other_id: any other identifying number/code/handle/URL: user IDs, IP addresses, work permit numbers, practitioner registration numbers,
#   policy/claim/account/accession/ticket/referral/prescription numbers, trial subject IDs, employee and staff numbers, blood unit numbers.
# - Year of birth alone (e.g. "M/1961") is labelled dob. A phone number spelled out in words is labelled phone.
# - Chat/message/log timestamps that carry a date are labelled date_other (the date-bearing part, time included when fused); bare times are not.
# - Decoys left unmarked: organisation names, ward/bed/room numbers inside hospitals, lab values, doses, times, ICD codes, device models,
#   lot numbers, protocol/form/document numbers, software versions, printer/workstation names, generic event dates not about a person's care,
#   town names on their own (e.g. "tampines").
# - Emails and URLs use only example.com / example.org / example.net (and subdomains). IP addresses use the 203.0.113.0/24 documentation range.
# - All full NRIC/FIN values carry valid checksums. Deliberately invalid IDs: NONE. OCR misreads in v18_n08 affect only the referral ref,
#   DOB, address, postal code and phone values (labelled as written), not the NRIC.
# - Negative controls (no identifiers at all): v18_n05, v18_n11, v18_n17, v18_n23, v18_n29.
